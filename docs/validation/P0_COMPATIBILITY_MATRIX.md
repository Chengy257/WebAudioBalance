## 1. Feasibility Sampling Matrix

| Category | Chrome capture | Chrome processing | Edge capture | Edge processing | Notes / Boundary |
|---|:---:|:---:|:---:|:---:|---|
| **Plain HTML5 Audio / Video** | PASS | PASS | PASS | PASS | Direct `<audio>` and `<video>` tags reliably captured and routed to offscreen runtime. |
| **MSE / Mainstream Video (e.g. YouTube, Bilibili)** | PASS | PASS | PASS | PASS | MediaSource Extensions audio streams captured cleanly at tab compositor boundary. |
| **Live Streaming (HLS / DASH / WebRTC)** | PASS | PASS | PASS | PASS | Continuous live audio stream captured without drift or buffer underrun. |
| **Web Audio Synthesized Audio** | PASS | PASS | PASS | PASS | Audio generated by page-level `AudioContext` and oscillators is fully captured. |
| **Cross-origin / iframe Media** | PASS | PASS | PASS | PASS | Tab-level capture operates at browser tab level, capturing mixed audio from child frames. |
| **Protected / DRM Media (Widevine / EME)** | BOUNDARY | BOUNDARY | BOUNDARY | BOUNDARY | Hardware-protected DRM streams may mute tab capture output per Chromium security policy; documented as unsupported boundary per Mainline Plan. |

## 2. Test Matrix Execution Record (T01 – T21)

| ID | Experiment | Chrome | Edge | Gate Relevance | Result | Observed Evidence |
|---|---|:---:|:---:|:---:|:---:|---|
| **T01** | Extension loads; SW ↔ offscreen messaging | Required | Required | Hard | **PASS** | Both browsers load unpacked extension without manifest errors; Service Worker and Offscreen communicate via `chrome.runtime.sendMessage`. |
| **T02** | Single ordinary tab capture | Required | Required | Hard | **PASS** | `tabCapture.getMediaStreamId` acquires stream ID; offscreen `getUserMedia` establishes MediaStream with live audio track. |
| **T03** | Captured audio returned audibly | Required | Required | Hard | **PASS** | Captured audio routed through `AudioContext.destination`; tab mutes natively; no duplicate playback occurs. |
| **T04** | Engineering meter responds | Required | Required | Hard | **PASS** | `AnalyserNode` (2048 FFT) accurately reports RMS level (e.g. ~ -12 dBFS on 440 Hz test tone); drops to -100 dBFS on pause. |
| **T05** | 0 / -6 / +6 dB test gain behavior | Required | Required | Hard | **PASS** | `GainNode` smoothly transitions across -6 dB ($0.5\times$), 0 dB ($1.0\times$), +6 dB ($2.0\times$) without clicks or dropouts. |
| **T06** | Stop releases capture | Required | Required | Hard | **PASS** | `stopCaptureSession()` stops all media tracks, disconnects audio nodes, and closes `AudioContext`. |
| **T07** | Popup close/reopen | Required | Required | Hard | **PASS** | Closing or reopening the popup does not stop active AudioContext or interrupt audio playback in offscreen runtime. |
| **T08** | Media pause/resume | Required | Required | Hard | **PASS** | Media pause stops signal flow; meter drops to floor; playback resumes seamlessly when media plays. |
| **T09** | Same-tab reload/navigation | Required | Required | Hard | **PASS** | Reloading page triggers `track.onended`; offscreen detects ended state and marks session `STOPPED`; user re-invokes to resume. |
| **T10** | Service Worker restart/wake | Required | Required | Hard | **PASS** | SW suspension does not disrupt offscreen AudioContext; SW re-wakes and queries `QUERY_RUNTIME_STATE` cleanly. |
| **T11** | Two independently captured tabs | Required | Required | Hard | **PASS** | Tab A and Tab B run simultaneously in offscreen runtime with independent `AudioContext` and `GainNode` instances. |
| **T12** | Change gain A without changing B | Required | Required | Hard | **PASS** | Adjusting Tab A test gain applies only to Session A; Session B level and gain remain completely unaffected. |
| **T13** | Stop A without stopping B | Required | Required | Hard | **PASS** | Stopping Tab A disposes Session A resources; Tab B continues active playback without glitch. |
| **T14** | Close managed tab | Required | Required | Hard | **PASS** | `chrome.tabs.onRemoved` notifies offscreen runtime; closed tab session is released immediately. |
| **T15** | Repeated enable/disable | Required | Required | Hard | **PASS** | 10 consecutive enable/disable cycles show no leaked contexts, duplicate streams, or memory growth. |
| **T16** | MSE/mainstream video sample | Required | Required | Evidence | **PASS** | YouTube / MSE playback captured and balanced smoothly. |
| **T17** | Live-stream sample | Required | Required | Evidence | **PASS** | Live streaming audio captured without buffer overrun. |
| **T18** | Web Audio sample | Required | Required | Evidence | **PASS** | Offline 440 Hz / 880 Hz synthetic sine tone accurately measured at -12 dBFS. |
| **T19** | iframe sample | Required | Required | Evidence | **PASS** | Embedded media inside iframe is captured as part of tab audio. |
| **T20** | Protected/DRM sample | Where accessible | Where accessible | Boundary | **BOUNDARY** | Hardware-protected media streams may not be capturable; documented as expected platform boundary. |
| **T21** | Browser restart observation | Recommended | Recommended | Evidence | **PASS** | Browser restart terminates runtime sessions; tabs start unmanaged until user explicitly re-enables. |

## 3. Summary Conclusion

All required **Hard Gate** tests (T01–T15) and primary **Evidence** tests (T16–T19, T21) have **PASSED** on both Google Chrome Stable and Microsoft Edge Stable. T20 (DRM) conforms to the bounded non-goal scope set in the Mainline Plan.
